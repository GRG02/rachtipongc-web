## 📖 Overview | ภาพรวมโปรเจกต์

**Rachtipong Web** เป็นเว็บไซต์พอร์ตโฟลิโอส่วนตัวและศูนย์รวมผลงานทางเทคนิคของ **รัชติพงษ์ ชัยปราบ (Rachtipong Chaiprab)** ผู้สำเร็จการศึกษาเทคโนโลยีบัณฑิต (ทล.บ.) เกียรตินิยมอันดับหนึ่ง มหาวิทยาลัยเอเชียอาคเนย์ (GPA 3.92) และผู้ช่วยสอน (Teaching Assistant) ด้าน AI, Cloud, และ Microsoft 365 

เว็บไซต์นี้พัฒนาด้วยสถาปัตยกรรมยุคใหม่ **Next.js 16 (App Router)** ร่วมกับ **React 19**, **TypeScript** และ **Chakra UI v3** ออกแบบบนธีม **Supabase-inspired Cool Dark Theme** ที่เน้นความเรียบหรู คมชัด รองรับระบบสองภาษา (EN | TH) แบบสลับได้ทันที และออกแบบให้ Responsive สมบูรณ์แบบบนทุกอุปกรณ์

## ✨ Key Features | จุดเด่นสำคัญ

- **🎨 Supabase Dark Aesthetic**: โทนสีเข้มพรีเมียม `#0a0a0c` และ `#17181c` พร้อมไฮไลต์สีเขียวสดชื่นสไตล์ Supabase (`#9bdb6b`) ขอบมน และแอนิเมชัน Hover นุ่มนวล
- **🌐 Real-Time Bilingual Toggle**: รองรับ 2 ภาษาเต็มรูปแบบ ทั้งภาษาไทยและภาษาอังกฤษ สามารถสลับภาษาได้ทันทีผ่าน `LanguageContext` ทั่วทั้งแอป
- **⚡ Next.js 16 & React 19 Engine**: สถาปัตยกรรม App Router ที่รองรับ Static Site Generation (SSG) ทำงานรวดเร็ว โหลดหน้าทันใจ และเป็นมิตรกับ SEO
- **🧩 Chakra UI v3 Modern Primitives**: ใช้งานคอมโพเนนต์มาตรฐาน Chakra v3 (Snippets pattern) เช่น `Dialog`, `Drawer`, `Tabs`, `Flex`, `Grid` พร้อม Lightbox แสดงภาพและใบรับรองความละเอียดสูง
- **📱 Universal Responsiveness**: แสดงผลไร้รอยต่อทั้งบนมือถือ (Mobile Hamburger Drawer), แท็บเล็ต และคอมพิวเตอร์เดสก์ท็อป
- **🛡️ VirusTotal Clean & Verified Projects**: ระบบจัดแสดงโปรเจกต์ซอฟต์แวร์จริง พร้อมผลตรวจความปลอดภัยสากล 100% Clean จาก VirusTotal

## 🚀 Getting Started | วิธีการติดตั้งและรันโปรเจกต์

### ข้อกำหนดเบื้องต้น (Prerequisites)
- [Node.js](https://nodejs.org/) เวอร์ชัน 20.x ขึ้นไป
- [npm](https://www.npmjs.com/) หรือ [yarn](https://yarnpkg.com/) หรือ [pnpm](https://pnpm.io/)

### 1. โคลนคลังโค้ด (Clone Repository)
```bash
git clone https://github.com/GRG02/rachtipongc-web.git
cd rachtipongc-web
```

### 2. ติดตั้ง Dependencies
```bash
npm install
```

### 3. รัน Development Server
```bash
npm run dev
```

เปิดเบราว์เซอร์ไปที่ [http://localhost:3000](http://localhost:3000) เพื่อดูผลลัพธ์

### 4. Build สำหรับ Production
```bash
npm run build
npm run start
```
